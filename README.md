# Procrastination Lab

A standalone HTML/CSS/JavaScript reflection tool inspired by the ideas in Tim Urban's
2016 TED Talk, "Inside the Mind of a Master Procrastinator", with an additional
research layer around present bias, task aversiveness, and emotion regulation.

## Files

- index.html
- style.css
- script.js

## Run

Open `index.html` in a browser.

No build step, framework, backend, or npm packages are required.

## What it does

1. Captures the exact task being delayed.
2. Asks about immediate distraction reward, task aversion, and clarity.
3. Builds a simple procrastination map using transparent heuristics.
4. Suggests a practical intervention.
5. Starts a focused session timer.
6. Provides research/source links.

The score is deliberately presented as a reflection heuristic, not a psychological
diagnosis or validated clinical assessment.

## Research basis

The tool draws conceptually from:

- Tim Urban, TED: Inside the Mind of a Master Procrastinator.
- Tim Urban, Wait But Why: The Procrastination Matrix.
- Steel (2007), The Nature of Procrastination: A Meta-Analytic and Theoretical Review.
- Sirois & Pychyl (2013), Procrastination and the Priority of Short-Term Mood Regulation.
- Research overviews discussing temporal motivation, task aversiveness, delay, and immediate rewards.

The original wording, UI, scoring system, and implementation in this project are newly written.
